# Radoje Laušević — website and Pages CMS

Privatni izvorni repozitorijum za Cloudflare Pages.

- CMS: https://app.pagescms.org/ — izaberite rlausevic/radoje-lausevic-website, main.
- Image processing dependency: `python3 -m pip install -r requirements.txt` (also installed automatically by the build if missing).
- Build command: `python3 build.py && python3 validate.py`
- Build output directory: `dist`
- Framework preset: None
